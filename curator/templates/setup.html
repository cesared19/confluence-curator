1 Confluence

La que ves en el navegador al abrir Confluence, hasta .atlassian.net.

¿Cómo consigo el token?
  1. Abre id.atlassian.com → Seguridad → Tokens de API con tu cuenta.
  2. Pulsa Crear token de API, ponle un nombre como «Confluence Curator» y una fecha de vencimiento.
  3. Copia el token y pégalo aquí. Atlassian no lo vuelve a mostrar.

La herramienta edita Confluence con esta cuenta: los cambios aparecen a su nombre y solo puede tocar lo que la cuenta puede editar.

Pulsa Probar conexión para elegirlo de la lista. La clave también aparece en la dirección del espacio: /wiki/spaces/CLAVE/…

2 Jira (opcional)

Es lo habitual: Jira y Confluence comparten la cuenta de Atlassian. La herramienta solo lee Jira; no cambia tickets.

3 Chat (opcional)

Para importar conversaciones del chat del equipo. Hoy funciona con Slack; con otro chat, los mensajes se pegan en la bandeja.

¿Cómo consigo el token?
  1. Abre api.slack.com/apps, pulsa Create New App → From scratch, ponle un nombre como «Confluence Curator» y elige el espacio de trabajo. Es una app interna, solo para ese espacio.
  2. En OAuth & Permissions agrega estos permisos: channels:read, channels:history, groups:read, groups:history, users:read y files:read.
    • Como User Token Scopes: la herramienta lee los canales en los que estás tú. Es lo más simple.
    • Como Bot Token Scopes: lee solo los canales a los que invites la app con /invite @Confluence Curator.
  3. Pulsa Install to Workspace (puede requerir la aprobación de quien administra Slack) y copia el token que empieza con xoxp- o xoxb-.

La herramienta solo lee mensajes: no escribe en Slack.

4 Inteligencia artificial

Decide dónde va cada información y redacta los cambios. Puedes cambiarla cuando quieras.

Se crea en console.anthropic.com → API keys. El uso se cobra por consumo en esa cuenta.

Para leer imágenes elige uno con visión, como gemma3. Para descargarlo, en una terminal: ollama pull gemma3:12b

Elige el tamaño según la memoria del equipo: gemma3:12b va bien con 16 GB; gemma3:27b necesita 32 GB o más. Con un modelo demasiado grande, cada análisis puede tardar muchos minutos; el bloque Actividad muestra si avanza.
